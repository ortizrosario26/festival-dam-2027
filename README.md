# Festival DAM 2027

Web estática de un festival de música ficticio, creada para la Práctica 2 de Entornos de Desarrollo (1.º DAM).

## Páginas

- `index.html`: presentación y datos generales.
- `programa.html`: artistas, escenarios y horarios.
- `entradas.html`: tipos de entradas y precios.
